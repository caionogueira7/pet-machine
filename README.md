#  Pet Machine em Java

Projeto desenvolvido para praticar conceitos fundamentais de **Programação Orientada a Objetos (POO)** em Java. Trata-se de uma aplicação de terminal que simula o funcionamento e o controle de uma máquina de banho automatizada para animais de estimação.

##  Funcionalidades do Sistema

O sistema permite interagir com a máquina através de um menu de opções no console:
- **Gestão de Água:** Abastecer e verificar o nível atual do reservatório de água.
- **Gestão de Shampoo:** Abastecer e verificar o nível atual do reservatório de shampoo.
- **Controle de Pets:** Colocar o pet na máquina, verificar se há algum animal presente e retirá-lo.
- **Ciclo de Banho:** Executar o banho consumindo os recursos necessários.
- **Manutenção:** Realizar a limpeza da máquina após o uso.

##  Tecnologias Utilizadas

- **Java** (Linguagem principal)
- **Orientação a Objetos (POO)** (Encapsulamento, classes e métodos)
- **IntelliJ IDEA** (Ambiente de desenvolvimento)
- **Git & GitHub** (Controle de versão)

##  Como Executar o Projeto

1. Certifica-te de que tens o **Java JDK** instalado no teu computador.
2. Clona este repositório ou descarrega os ficheiros fonte (`.java`).
3. Abre o projeto na tua IDE de preferência (como o **IntelliJ IDEA**).
4. Executa a classe principal **`Main.java`**.
